# Сбор статистики для оптимизации русских раскладок для слепопечатников
Данный проект представляет собой программу для анализа различных клавиатурных раскладок (русских)

- Рассмотренные раскладки:
	- Йцукен
	- Вызов
	- Диктор
	- Скоропись

## Лабораторные и как их запустить

### Установка Git
Для клонирования репозитория со всеми лабораторными через консоль нужен установленный **Git**:
#### Linux
```
sudo apt install git
```
#### Windows
-  [Ссылка на установщик](https://git-scm.com/downloads/win)

## Вывод

ЙЦУКЕН
📎 Это стандартная русскоязычная раскладка, используемая на компьютерах.

Название образовано по первым шести буквам верхнего ряда клавиатуры.

Впервые появилась на пишущих машинках.

Раскладка ЙЦУКЕН
—

Вызов
📎 Это альтернативная русская клавиатурная раскладка, созданная для более удобного и быстрого набора текста по сравнению с классической ЙЦУКЕН.

Минимизация движений.

Частотный принцип: часто используемые символы попадают под сильные пальцы(указательные и средние).

Раскладка Вызов
—

Русфон
📎 Это одна из альтернативных русских клавиатурных раскладок, основанная на фонетическом принципе.

Каждая русская буква ставится на клавишу, где в латинице находится похожая по звучанию буква.Например: A → А,B → Б,V → В,G → Г,K → К,M → М,N → Н,O → О,P → П,S → С,T → Т.

Удобна для билингвов.

Раскладка Русфон
—

Скоропись
📎 Главная идея - скоростной набор текста

Буквы распределены так, чтобы минимизировать движения пальцев. Часто встречающиеся символы находятся в центральной зоне клавиатуры.

Частотный принцип.

Минимизация движений.

Оптимизация для слепого метода.

Раскладка Скоропись
—

Диктор
📎 Создана для тех, кто работает работает с большим объемом текста.

Частотное расположение букв - часто употребляемые символы вынесены на «домашний ряд».

Включает поддержку сокращений.

Раскладка Диктор
Ант
📎 Ориентирована на скорость и эргономику.

Сбалансированность по рукам.

Уменьшение амплитуды движений.

Раскладка Ант
Зубачев
📎 Создана для оптимизации набора текста. Попытка усоверщенствовать ЙЦУКЕН.

Симметрия: движения левой и правой руки сбалансированны.

Снижение движений: пальцы реже уходят в верхний и нижний ряды.
